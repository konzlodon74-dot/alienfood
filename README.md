> One star: your saucer parking is atrocious and locals keep photographing my tentacles, but your tacos alone justify the 400 light-year trip.

## How it works

`main.py` holds the alien's one-sentence review as a constant, asserts it is non-blank, single-line, exactly one sentence, and at most 200 characters, then writes it as UTF-8 bytes with no trailing newline to `/output/entry.txt`, creating the output directory if needed.

## Run

```bash
python3 main.py
cat /output/entry.txt
```
